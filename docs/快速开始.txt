DOTA2 教练 · 快速开始
======================

一、双击运行
------------
Dota2Coach\Dota2Coach.exe         主窗口版（推荐）：阵容、技能简介、状态、设置、帮助
Dota2Coach-Card\Dota2Coach-Card.exe   只显示右上角置顶卡片

首次运行会自动在 exe 旁边生成 logs\ 目录。
配置写在 exe 旁边的 config.toml；如果目录不可写，会自动改用 %LOCALAPPDATA%\Dota2Coach。

二、让游戏把数据发给教练（只需做一次）
--------------------------------------
1. 打开 Steam → 库 → 右键 Dota 2 → 管理 → 浏览本地文件；
2. 进入 game\dota\cfg\ 新建文件夹 gamestate_integration；
3. 把 说明\gsi.cfg 复制进去，改名为 gamestate_integration_coach.cfg；
4. 重启 Dota 2。

三、游戏设置建议
----------------
- 视频：窗口模式或无边框窗口（全屏独占也能用，但窗口更稳）；
- HUD 缩放保持默认 100%，分辨率不要频繁改（改了程序会自动重新定位）。

四、使用
--------
1. 启动 Dota2Coach.exe，点“开始”（右下状态灯变绿）；
2. 进对局：主窗口自动切换成双方 10 个英雄，每个英雄两条关键技能；
3. 右上角卡片给出对线/出装/团战提示，并语音播报；
4. F8 显示/隐藏卡片；F9 试听语音；关窗口缩到托盘。

五、常见问题
------------
- 状态灯“GSI 监听”不亮：GSI 配置没放对，或端口 31982 被占用（关掉旧实例）。
- “识别 n/10”偏低：进对局 1.5 秒后会自动重新定位顶部栏；
  如果一直低，确认游戏是窗口/无边框，并看控制台/日志里的 [识别] 行。
- 没有声音：设置 → 语音 → 后端选“在线 edge-tts”，并确认能联网。
- 想看日志：帮助 → 打开日志目录。

六、更新数据（可选）
--------------------
本包只含运行所需数据，不带动更新脚本。需要更新英雄/物品/攻略数据时，
用源码目录里的 scripts\update_data.ps1、update_guides.ps1。

七、合规
--------
只读取官方 GSI 报文 + 你自己屏幕的截图；不读内存、不注入、不模拟按键、不改包。
定位个人训练/复盘使用。
